# 認証アップデートの当て方（いつもの月次更新と同じ・3分）

⚠️ このアップデートは「Claudeに貼って適用」だと、キットの安全保護で止まります（「お応えできません」と出ます）。
**いつもの月次更新と同じ「ファイルをドラッグ＆ドロップ」**でお願いします。新しい操作ではありません。

## ⚠️ 当てる場所
**ホグワーツのキットのフォルダ**に当ててください（ローンチマスター等の**別キットのフォルダには当てない**でください）。

## 手順（いつもの更新と同じ感覚）
1. このZIPを**解凍**する
2. Claude Code で **ホグワーツのキットのフォルダを開く**
3. 解凍フォルダの中の **`.github` フォルダ** と **`scripts` フォルダ** を、
   Claude Code 左側のファイル一覧（または エクスプローラー）に **ドラッグ＆ドロップして「上書き」** する
   - ※ ポイント：**Claudeに「編集して」と頼まず、自分でドラッグ**します（いつもの更新と同じやり方）
4. チャットに「**変更を全部 git add して commit して push して**」と入力（これは編集ではないので止まりません）
5. GitHubのあなたのリポジトリ → **Settings → Secrets and variables → Actions → New repository secret**
   - **Name**：`DISCORD_USER_ID` ／ **Value**：あなたのDiscordユーザーID
     - 取得：PC版Discordで自分のアイコンを右クリック →「ユーザーIDをコピー」（出ない場合は 設定→詳細設定→「開発者モード」ON）

これで完了です。

## もし「お応えできません」と出たら
保護が正常に効いている合図です。**Claudeに“編集”を頼むのをやめて、手順3の“自分でドラッグ＆ドロップ”に変えれば**通ります。
うまくいかない時は、コミュニティ管理者が一緒に対応します🙆 お気軽にどうぞ。
