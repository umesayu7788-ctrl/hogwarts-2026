# アフィリ方針：オーガニックアガベシロップ（オーナー決定 2026-08-01）

## 決定
**オーガニックアガベ** を甘みアフィリの第一候補として進める。

## 教育 → アフィリの流れ
1. 低GIとは何か（説明済み・継続可）
2. 白砂糖との違い・急激な血糖上昇を意識する話
3. 量・食べ合わせ注意（果糖多め・摂りすぎ注意を一言）
4. **アフィリ日 SLOT_3** でオーガニックアガベを1商品紹介（#PR）

## 投稿ルール
- 1投稿1商品
- `#PR` / `#広告` 必須（ツリー側ルールに従う）
- NG：血糖が上がらない／糖尿病が防げる・治る／低GI＝食べ放題
- OK：「低GIと言われてる」「急上昇を意識しやすい選択肢」「体への負担を小さくする工夫」

## きび糖・てんさい糖との役割分担
| 商品 | 役割 |
|---|---|
| オーガニックアガベ | **アフィリ主力**・低GI・ドリンク／冷たいものにも |
| きび糖 | 素材感・煮物コク（低GI主役にしない） |
| てんさい糖 | 腸活（オリゴ糖）接続・次点アフィリ候補 |
