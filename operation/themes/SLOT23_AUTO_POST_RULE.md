# SLOT_2/3 自動投稿が成功する条件（運用メモ）

## 結論
自動投稿（SLOT_2・SLOT_3）は **github-actions[bot] が書いた「承認申請」内の推奨投稿案** しか読めない。

## NG（失敗する）
- 人間アカウントで確定文だけ貼って「承認」
- 途中差し替えを人間コメントだけでやる

## OK（成功する）
1. 日次ループで bot が照史→淳太→小瀧（承認申請）まで書く
2. オーナーが Issue に「承認」とコメント
3. SLOT_1 即時 / SLOT_2 18:00 / SLOT_3 21:00

## 文面を変えたいとき
Issue に `修正: （指示）` とコメント → Correct ワークフローで **bot側の文** を作り直す → 再度「承認」

## 18時を過ぎた場合
「承認」後に SLOT_2 ワークフローを手動実行すれば投稿できる。
