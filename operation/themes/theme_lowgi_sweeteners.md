# 甘み・低GI・代替商品メモ（2026-08-01）

## 低GIって何？（投稿で必ず噛み砕く）
- GI＝グリセミック・インデックス
- 食後に血糖がどのくらい速く上がりやすいかの目安
- 一般に **55以下が低GI**、56–69が中、70以上が高、と言われることが多い
- 「上がらない」ではなく「上がり方が急になりにくいと言われる」

## 商品ごとの整理（断定しすぎない）
| 甘み | イメージ | 投稿での扱い |
|---|---|---|
| アガベシロップ | 低GIと言われやすい（目安15–30前後の記述が多い） | 急上昇を意識する選択肢。量・食べ合わせ注意。果糖多めなので摂りすぎ注意も一言 |
| きび糖 | **低GIとは言い切れない**（高め〜中高の記述が多い） | 「ミネラルが残りやすい／素材感」向き。低GI主役にはしない |
| てんさい糖 | 白砂糖よりGI低めの記述が多い＋**オリゴ糖**で腸活接続しやすい | オーガニック／腸活の主力候補 |
| ココナッツシュガー | 低〜中GI寄りと言われることあり | 代替候補 |
| メープル | 中GI前後の記述が多い | 素材系の置き換え |
| 羅漢果・オリゴ糖 | GIとても低めと言われやすい | アフィリ候補。味・用途の説明を丁寧に |

## アフィリ方針
- **第一候補: オーガニックアガベ**（`theme_affi_organic_agave.md`）
- 教育投稿で「低GIとは」→ アフィリ日に商品1つ
- 1投稿1商品・#PR必須・効能断定なし
- きび糖は「料理のコク・素材感」枠（低GI主役にしない）
- てんさい糖は腸活接続の次点候補
