# 投稿のわかりやすさ（オーナー指示 2026-08-04）

## 指摘
朝投稿が「何が言いたいか」伝わりにくい。ふわっと感は朝でもOKだが、**半身浴が何か／何がうれしいか**が抜けているとフォロー理由にならない。

## 必須の伝え方
1. **半身浴・ぬるめ**を一言で説明する（おへそ〜みぞおちまで／熱くない温度 など）
2. **体感の変化**を具体でつなぐ（例）
   - 日中エアコンで冷えた体 → ぬるめ半身浴でゆっくり温まる感じ
   - めぐりが戻った感じ → 暑苦しい夜でも寝つきが楽だった
3. 最終ゴール：読者が「この人、ためになる話してる → フォローしておきたい」と思う

## OK / NG
- OK：体感・感じ・私の場合／続きやすい
- NG：治る・効く・必ず眠れる・血流が必ず良くなる などの断定
- 洗腸・快便定番は休みのまま

## 朝枠のコツ
- ふわっと入ってOK
- ただしツリーのどこかで「何の話か＋何がうれしいか」を1セット入れる
