# 外部メモリ：GitHub Issues 運用ガイド

このフォルダは説明書だけを置く場所です。**実際のデータは GitHub Issues に保存されます。**
ローカルにログを溜めないので、PCを買い替えても記録は消えません。

## 仕組み

1日1本、その日の運用Issueが自動で立ちます。各担当はそのIssueに**コメントを追記**して
バトンを渡します（情報リサーチ → ライター → 校閲 → 投稿・計測）。

| 記録される内容 | どこを見るか |
|---|---|
| 当日のブリーフィング・投稿案・校閲結果 | その日のIssueのコメント |
| 投稿後のエンゲージメント | 投稿・計測担当が24時間後に追記 |
| 週次の成果まとめ | `operation/weekly/` |

## あなたがやること

**普段は何もありません。** 過去の投稿や数字を振り返りたいときに、
GitHubのIssues一覧を日付で辿ってください。

## 注意

- Issueを手で閉じても問題ありません（記録は残ります）
- Issueを**削除**すると記録は戻せません。消さないでください
