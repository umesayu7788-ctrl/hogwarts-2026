# 心理誘導アフィリ投稿のナレッジ（潜在意識アプローチ）

> **このナレッジはライター・校閲・コンプライアンス担当が必ず参照する。**
>
> 目標：読者が **「気づいたらリンクをタップしてた」「買ったけど後悔がない」** という状態を作る。
> 押し売り感ゼロ。商品名は最後。あくまで「自分の体験・気づきを共有する友達」として。
>
> ⚠️ **以下の例文は説明用サンプルです。**
> あなたのジャンルに合わせて言葉を置き換えて活用してください。
> 心理トリガーの「型」が普遍的なポイントなので、文章自体を真似する必要はありません。

---

## 🎯 大前提：押し売りはNG・後悔させない

### NGアプローチ（即アンフォロー誘発）
- 「絶対買って！」「これ最強！」「今すぐ！」
- 商品名を冒頭から連呼
- リンク文を煽る（「お早めに！」「在庫残りわずか！」を多用）
- ポジティブだけ書く（不自然な完璧描写）
- 「私の紹介リンクから買って」（楽天規約違反）

### OKアプローチ（自然な誘導）
- 自分の悩み・失敗から入る
- 解決のプロセスを語る
- 商品名は本文の真ん中〜後半に1度だけ
- 良い面と「気をつけたい点」を両方書く
- 「気になったら覗いてみてね」程度の誘い

---

## 🧠 8つの心理トリガー（潜在意識へのアプローチ）

### 1. ストーリーテリング（最強の誘導手段）

**人は商品ではなく「自分が変わるストーリー」を買う**

NG：
> このパジャマ、冷感素材で快適です

OK：
> 夏の夜、子どもが汗だくで何度も起きて
> 私もずっと寝不足だったんだよね
> でも、ある日素材を変えたら…
> 朝までぐっすりで、私もびっくりしちゃった

**ポイント：**
- 過去の苦悩 → 試行 → 変化のストーリー
- 「商品を買う前→買った後」の人生変化を見せる
- 数字より感覚（「ぐっすり」「肌触り」「朝の機嫌」）

---

### 2. 五感への訴求（潜在意識の入口）

**理性（脳）ではなく、感覚（体）に訴える**

抽象 → 具体に変換：
- 「気持ちいい」→「お腹のあたりがすーっとして、深呼吸しちゃう」
- 「快適」→「シーツに触れた瞬間、肩の力が抜ける」
- 「効いた」→「2日目の朝、起きた瞬間、あ、いつもと違うって思ったの」

→ 読者の脳内で**仮想体験**が起きる → 「これ私も体験したい」が無意識に発火

---

### 3. アンカリング（基準点を先に見せる）

**最初の数字が判断基準を作る**

例：
> 寝不足のママの平均睡眠時間って、4〜5時間なんだって（参照点）
> でも私、これ使い始めてから6時間以上眠れる日が増えたんだよね（変化）
> 1日90分、私の人生に時間が戻ってきた感覚（価値の翻訳）

→ 4〜5時間という数字が脳に刻まれた後、6時間という変化が大きく見える

---

### 4. 社会的証明（みんな選んでる）

**人は他人の選択を判断材料にする**

```
楽天で★4.3、レビュー2840件
「夜泣きが減った」「これで救われた」って書いてる人多くて
共働きママの間で密かに流行ってるみたい
```

**ポイント：**
- 具体的な数字（★評価・レビュー数）
- 同じ立場の人（共働きママ・夜泣きで悩んでた人）
- 「密かに」「ひっそり」の控えめワードで自然さUP

---

### 5. 損失回避（得より失うのが怖い）

**「得する」より「失わずに済む」のほうが2倍刺さる**

NG（利得フレーム）：
> これがあれば毎日6時間眠れます！

OK（損失回避フレーム）：
> 夜泣きで毎晩起きてた頃、私、子どもにイライラしちゃってたんだよね
> 今思うと、あの時の自分、可哀想だった
> もう、あの頃には戻りたくない

→ 「損失（イライラ・自己嫌悪）を避けたい」が無意識に発動

---

### 6. 失敗回避（私もこれで失敗した）

**先に失敗談を見せると、後の成功が信頼される**

```
最初、安いの買って失敗したんだよね
1ヶ月でへたってきて、結局買い直し
で、調べ直して買い直したのがこれ
最初からこっちにしておけばよかった、って思った
```

→ 「失敗してほしくない」という親心モード発動 → 自分も同じ失敗したくない → クリック

---

### 7. 未来想起（買った後の自分を見せる）

**読者の頭の中で「すでに使ってる自分」を再生させる**

> 夜中に起きずに朝までぐっすり眠れる
> 朝、子どもが「ママおはよう」って笑顔で起きてくる
> その日、自分も心に余裕があって、優しくいられる
> ……そんな日常が、月にあと10日増えるとしたら？

→ 読者の脳が**未来体験のシミュレーション**を始める → 「これは私の現実になりうる」と思った瞬間に欲しくなる

---

### 8. 専門家・権威の借用（自分の肩書き視点）

**自分の権威性を「自然に」混ぜる**（buzz_posts.mdで定義した自分の肩書き・経歴を活用）

NG（押し付けがましい）：
> {{あなたの肩書き}}{{年数}}の私が選んだ商品です！買ってください！

OK（自然に匂わせる）：
> プロでも、自分のことになると別なんだよね
> {{自分の経験領域}}でいろんな人を見てきて
> その中で「これ救世主だった」って何度も聞いた商品があって…

→ 権威を主張せず、**経験の蓄積として匂わせる**だけで信頼が乗る

## 🏗️ 黄金構造：心理誘導×参考バズ統合（7ステップ）

```
1. 共感呼びかけ・自己開示（感情の門を開く）
   「夜泣きでクタクタなママ、わかる、私もそうだったよ」

2. 失敗・葛藤の告白（信頼を作る）
   「最初、適当に買って失敗したんだよね」

3. 試行錯誤の物語（ストーリー）
   「で、調べて、見つけたのがこれ」

4. 五感ベースの体験描写（仮想体験）
   「使ってみたら、肌触りがすーっとして…」

5. 数字・専門性で根拠補強（権威）
   「楽天★4.3、{{自分の肩書き}}視点でも納得」

6. 未来想起（購入後の自分）
   「夜中に起きずに朝までぐっすりな朝、想像できる？」

7. 控えめなCTA（自由意志を残す）
   「気になったら覗いてみてね、私はここに置いとくね」
```

各ステップ、**1〜2文で簡潔に**。長文だと熱が冷める。

## 🚫 後悔買いを生まない3原則

### 原則1：商品の弱点も伝える

```
ただし、洗濯はちょっと注意が必要で
ネットに入れて優しく洗わないと、毛羽立ちやすいかも
そこさえクリアすれば、長く使えるよ
```

→ **欠点を先に出すと、長所がより信頼される**（両面提示効果）

### 原則2：価格と価値の翻訳

価格だけだと「高い」と感じる商品も、**1日あたり・月あたり**に翻訳すると見え方が変わる。

```
3,980円って一見高く感じるけど
1年使えば1日あたり10円ちょっと
コーヒー1杯より安く、夜の安心が買えるって考えるとね
```

→ ただし**誇張禁止**。実際の使用期間で計算する。

### 原則3：「自分で決めた感」を残す

```
私の話をしただけだから
合うかどうかは、ママさん自身で確かめてみてね
```

→ 押し付けられた感がない＝後悔されにくい。

## ⚠️ コンプライアンス遵守ライン

心理誘導は強力だが、以下は絶対NG：

| NG | 理由 |
|---|---|
| 「絶対治る」「100%効く」 | 景表法・薬機法違反 |
| 競合品の貶め | 名誉毀損リスク |
| 嘘の体験談（使ってないのに使った風） | ステマ規制違反 |
| 「私の紹介リンクから買って」と直接依頼 | 楽天規約違反 |
| 「在庫残り○個！急いで！」（事実でないとき） | 不当表示 |

→ 「気持ちを誘導する」のはOK、**「事実を歪める」のはNG**

**親投稿**:


# 【追補】ジャンル軸 運用フレーム（2026-07-31 追加 / 運営配信）

> **なぜこのファイルに入っているか**（運営メモ・顧客が読んでも問題ない内容です）
> 各エージェントは長らく `genre_axis_strategy.md` というファイルを「必須」として参照していましたが、
> **そのファイルはどこにも存在しませんでした**。結果、ファネル設計・商品選定・校閲の判定基準が
> 丸ごと欠けたまま運用されていました（2026-07-31 是正）。
> 中身は運営が作る枠組みなので、すでに毎回配信されているこのファイルに追補します。
> **あなたが記入する欄はここにはありません。** あなた自身のジャンル設定は
> `operation/config/genre_config.yaml` と `buzz_posts.md`（声の定義）に書きます。

## 1. ジャンル軸とは

**「誰に・何を・どういう立場で」を一文で言い切ったもの。** すべての投稿がここに帰ってきます。

```
【型】 〈誰〉に向けて、〈何〉を、〈どんな立場〉から発信する
【例】 朝の15分だけは自分のために使いたい一人暮らしの社会人に、道具選びの失敗談を、
       10年ハンドドリップを続けてきた立場から
```

軸が無いアカウントは、投稿が毎回バラバラのテーマになり、読者が「何の人か」を覚えられません。
覚えられないアカウントはフォローされず、フォローされないので商品も売れません。
**低インプの多くは、フックの弱さではなく軸の不在が原因です。**

## 1-2. あなたの軸はすでに `buzz_posts.md` にあります（オーナーに聞かないこと）

「始める」の初期設定（STEP 4）で、オーナーはすでに次の4つを答えています。
**軸はこの4つを繋げれば組み立てられます。改めて質問してはいけません。**

| 初期設定の質問 | 軸のどの部分になるか |
|---|---|
| Q2 肩書き・専門性 | **どんな立場から** |
| Q3 ターゲット層 | **誰に** |
| **Q4 発信の軸（1文）** | **何を**（そのまま軸の中核） |
| Q5 世界観の中心 | 全テーマの帰着点 |

各担当は、毎回 `buzz_posts.md` からこの4つを読み、頭の中で1文に組み立ててから作業を始めてください。

```
【組み立て】 〈Q3〉に向けて、〈Q4〉を、〈Q2〉の立場から
```

`genre_config.yaml` の `product_keywords` は**商品検索用のキーワード**であって軸ではありません。
軸の判断にキーワードだけを使わないこと（何を売るかは決まっても、誰に何を語る人かが決まらないため）。

## 2. 投稿配分は 5:3:1（教育5 / 興味付け3 / アフィリ1）

出典は `threads_rakuten_problems.md`（「共感5:有益3:アフィリ1」）。
キット内で呼び名が揺れていますが、**すべて同じ3区分**を指します。以後この対応で統一：

| 本フレームの呼称 | 別名（他ファイル） | ライターの区分 | 中身 |
|---|---|---|---|
| **教育 5** | 共感 / 信用獲得 | `edu` | 商品紹介なし。学び・気づき・共感で信用を作る |
| **興味付け 3** | 有益 | `interest` | 商品紹介なし。「え、そうなの？」を引き出す |
| **アフィリ 1** | アフィリ | `affiliate` | 1投稿1商品。`#PR #広告` 必須 |

- **毎回リンクを貼らない。** 9投稿は売らずに信用を積む
- この比率は**週単位で満たす**。1日の中で無理に配分しない
- セール前日など勝負どころではアフィリを寄せてよいが、**週の合計で 5:3:1 に戻す**

## 3. ジャンル軸接続の1行（アフィリ投稿の必須要素）

アフィリ投稿には、**その商品がなぜ自分の軸から出てくるのかを説明する1行**を必ず入れます。
これが無いと「急に物を売り出した人」になり、フォロワーが離れます。

```
【型】 〈軸の悩み〉で困っていた時に、〈商品〉が〈どう効いたか〉
【例】 寝かしつけに1時間かかっていた時期に、これだけは効きました
```

**判定基準（校閲・コンプライアンス担当が使う）**

| 状態 | 判定 |
|---|---|
| 軸接続の1行がある | 通す |
| 商品説明だけで軸接続が1文もない | **差し戻し** |
| 軸と無関係なジャンルの商品 | **差し戻し**（商品選定からやり直し） |
| 軸接続が「便利です」「おすすめです」等の一般語だけ | **差し戻し**（具体の体験に書き換え） |

## 4. 各担当の使い方

- **商品リサーチ**：候補を出すとき、1件ごとに「軸接続の1行理由」を添える。書けない商品は**候補から外す**
- **情報リサーチ**：ブリーフィングに【ジャンル軸接続】欄を設け、この投稿が軸のどこに刺さるかを明示する
- **ファネル設計**：週次計画を 5:3:1 で組む。崩れていたら翌週で補正する
- **ライター**：アフィリ投稿では §3 の1行を必ず入れる。教育・興味付けでも軸から外れた題材は選ばない
- **校閲**：§3 の判定表で機械的に判定する。主観で緩めない
- **分析官**：軸接続の1行の有無と、クリック・購入の関係を記録する。
  **十分な件数が貯まるまでは相関を断定しない**（数件で「効果がある」と書かない）

## 5. `buzz_posts.md` が未記入のときだけの例外

通常は §1-2 のとおり `buzz_posts.md` から軸を組み立てます。
**「始める」を最後まで完了していれば必ず埋まっている**ので、このセクションは基本的に使いません。

Q2〜Q5 が `{{ }}` のまま残っている場合に限り、以下で回します。

1. 投稿は続ける。ただし**アフィリ投稿は保留**（軸が無い状態で売ると信用を削るだけ）
2. 教育・興味付けを 5:3 の比率で回し、反応が良かった題材を記録する
3. オーナーには「**初期設定の STEP 4 が途中で止まっています**」と1回だけ伝える。
   軸を新しく考えさせるのではなく、**すでにある手順の続きを案内する**（負担が段違いに軽いため）
4. 埋まったらアフィリを再開する

# 【追補】投稿の合否ライン（2026-07-31 追加 / 運営配信）

> 別チームのキットで先に実運用され、効果が確認できた基準をこちらにも入れます。
> **どれもジャンルを問いません。** 下の例はすべて説明用のサンプルなので、
> あなたのジャンルの言葉に置き換えて使ってください。

## A. 全投稿の必須3要素

**3つとも入っていない投稿は出さない。** 抽象的な良いことを書いただけの投稿は伸びません。

| 必須要素 | 何を入れるか | サンプル（ジャンルは置き換える） |
|---|---|---|
| **固有名詞** | ぼかさず名前で言う | 商品名・道具名・サービス名・場所・書名 |
| **具体的数字** | 量・時間・回数・金額 | 「3日」「1日10分」「2回目で」「1,200円」 |
| **読者の生活インパクト** | その人の1日がどう変わるか | 「朝の支度が10分早く終わる」「探し物をしなくなる」 |

- ❌ 悪い例：「便利なグッズを使うと生活がラクになります」（3つとも無い）
- ⭕ 良い例：「〈商品名〉に替えてから、朝の準備が10分縮んで、コーヒーを座って飲めるようになった」

**「生活インパクト」がいちばん抜けやすい**要素です。機能の説明で終わらせず、
「それで**読者の1日がどう変わるか**」まで必ず書ききってください。

## B. 使用禁止フック

内容が無いのに期待だけ煽る書き出しは、開かれても読まれず、エンゲージメント率を下げます。

**単独で使うことを禁止**

- 「プロ級の」「神レベルの」「最強の」
- 「ある質問」「あるもの」「あの方法」（何の話か分からない引き）
- 「最新の〇〇」（何が新しいのか書かないもの）

**理由**：中身を伏せる引きは一度は開かれますが、期待外れだと次から開かれなくなります。
**具体名を出したうえで意外性を作る**ほうが、長い目で見て伸びます。

- ❌ 「あるものを変えたら人生変わった」
- ⭕ 「〈商品名〉に替えただけで、10年やめられなかった〇〇をやめられた」

## C. 「バズった」の判定基準

自分の勝ちパターンを蓄積するとき、**何を成功とみなすかの線引き**です。

```
バズ判定 ＝ エンゲージメント率 2%以上  かつ  閲覧数 1,000以上
              （※どちらか片方ではなく、両方を満たすこと）
```

- **閲覧数だけで判定しない。** 閲覧が多くてもER（いいね・返信・保存などの反応率）が低い投稿は、
  「たまたま表示された」だけで**刺さっていません**
- 閲覧1,000以上でERが2%未満だった投稿は、成功例ではなく**反省サンプル**として扱う。
  同じ書き出し・同じ構成を繰り返さないこと
- この線引きが無いと、刺さっていない投稿が「自分の型」として溜まり続け、
  **弱い型を学習し続けることになります**

閾値の数値は運営が運用上定めたものです。あなたのアカウントが育って基準が合わなくなったら、
運営にご相談ください（自分で緩めないこと。緩めると上の学習事故が起きます）。
